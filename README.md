# Anarchy Arena

Open the HTML file in a browser. Choose Big Daddy or Gus and fight a three-stage ladder: the same rival returns as a tougher rematch and an unleashed boss, using the existing character art. Each match is best of three rounds. One continue retries a lost stage; quitting or exhausting it ends the run and submits any qualifying score. Wins award points for the stage, remaining time and health in the final round, damage and best combo. Qualifying scores enter a five-place initials table; fighter records and scores are saved locally when browser storage is available.

On the title screen, wait for the instructions and a non-scoring demo, or press any input to play. Press **G** on fighter select for the move guide. Arrow keys or A/D move, W/up jumps, down crouches, J punches, K kicks, L/S blocks, I performs the character special, and U performs a heavy attack. Touch users can use the stick and buttons; pressing punch and kick together is heavy. P or Escape pauses. Pause settings include difficulty, CRT, compact touch controls and gamepad presets. Use the button map to assign each action individually; tap a row or use left/right, with duplicate buttons swapped automatically. Buttons 9 and 12–15 remain reserved for Start and the D-pad. Navigate settings using touch, arrows and Enter, or the gamepad. Standard layout: south punch, east kick, west block, north special, left shoulder heavy; arcade preset: west punch, south kick, east block, north special, right shoulder heavy. Start pauses.

After a win, advance to the next stage; after a loss, continue once before the ten-second countdown expires or press Q to finish. On a touchscreen tap the result to advance or continue, or tap the end-run prompt. P, Escape or gamepad Start pauses the countdown; touch the pause overlay to resume. Enter initials with letters, arrows and Enter, gamepad directions and a face button, or the on-screen buttons.

Each ladder stage has its own synthesized music pattern. Round, fight and knockout announcements use the browser's available speech voice; browsers without speech support still show the on-screen calls. The sound-effects setting controls announcements and impacts separately from music. Reduced-motion system settings suppress screen shake and flashes and keep ambient stage and victory motion subdued.
